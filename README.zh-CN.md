# 课续 CourseRelay

课件下载了，学习稿没跟上；文件名都写着“最终版”，却不知道该打印哪份；下次让助手补资料，又要重新交代一遍。课续把这三件事放进一个本地课程台。

它读取你指定的课程目录，保存来源与稿件之间的明确关联，分别记住学习、复习和打印用途的选定版本。文件字节改变后，重新扫描会提示原关联和使用确认过期。所有私人索引留在本机。

## 打开

需要 Python 3.12 或更新版本，无需安装第三方依赖。

1. 将源码解压到独立目录。
2. Windows 双击 `start.cmd`；或在源码根目录运行 `python -m courserelay serve`。
3. 保持命令窗口开启。在浏览器中添加一门课程的本地目录，再点“重新扫描这门课”。

Linux 在源码根目录运行 `python3 -m courserelay serve`，使用绝对 Linux 路径。只监听 `127.0.0.1`，启动链接含临时会话令牌，请勿分享。

私人索引默认放在 Windows 的 `%LOCALAPPDATA%\CourseRelay` 或 Linux 的 `~/.local/share/CourseRelay`。换位置时：

```console
python -m courserelay --data-dir "D:\CourseRelayData" serve
```

索引必须放在源码和课程目录之外。应用不改写课件。退出时在命令窗口按 Ctrl+C；备份时先关闭服务，再复制 `index.sqlite`。

## 每天怎么用

**老师发新课件后**：下载到已添加的课程目录，重扫。在“待跟进”中查看尚无覆盖记录的来源。这里的“没有记录”不等于你没有读过。

**补完一份学习稿后**：点“查看与关联”，选择真实来源及实际稿件，写清已核对页码、题号、遗漏和依据。只处理了一部分就选“部分覆盖”。用途识别依据文件名作初步建议，可以手动改正。

**准备复习或打印时**：找到稿件，选择完整学习稿、精简复习稿或打印稿，点“采用当前扫描版本”。在“现在用哪份”查看各用途的选择；点“查看版本”可以下载经当前索引哈希核对的原文件副本。文件改变或不可读时会拒绝取用并提示重扫。

**担心有人改了最终稿时**：重扫会使旧确认失效。支持的格式可展示前后文字投影；哈希变化但文字相同，可能是图片、排版或属性改变，不会被当作字节相同。

**ZIP 与散装提交文件怕不配套时**：在“ZIP配套核验”选择 ZIP，填写当前文件目录相对于课程根目录的路径。只读核对成员哈希，不解压、不覆盖，也不决定哪一版正确。

**下次接着让助手补资料时**：导出 Markdown 交接单，先检查内容，再交给助手。它列出来源、关联范围、过期状态及当前用途版本；不会自动执行指令或上传课程文件。

## 适用边界

- 覆盖是人工声明。工具不认证答案正确、教学完整性、教师批准或提交合规。
- PDF、图片、旧 Office、XLSX 只做版本检查，正文是 UNKNOWN；没有 OCR、题目解答生成或自动更新笔记功能。
- DOCX/PPTX 只提取有界文字，不执行宏、公式、字段或嵌入对象；无法验证图片、公式、批注和完整排版。
- 默认扫描上限：5000 个文件、单文件 25 MiB、累计文件大小 512 MiB、12 层目录。缓存、音频、证据/历史目录及 Obsidian 的课件 PDF 副本等会被跳过。受深度、遍历错误或预算限制时明确标为扫描受限。
- 大小上限是输入/展开/文字预算，没有硬内存配额。重复大小写别名、非规范路径、加密、符号链接和过度展开的 ZIP 会被拒绝，可能拒绝合法但超限的文件。
- 状态表示上次扫描快照，不是实时监听。关联和采用动作会重新验哈希，但无法锁住其他程序今后的写入。下载只确认实际返回的字节哈希。
- 私人索引未加密。同一系统用户下的其他程序不在隔离保护范围内。不要把私人索引、交接单或课程截图放进公开仓库。

## 命令行

```console
python -m courserelay add "计算机网络" "D:\Courses\Networks"
python -m courserelay scan 1
python -m courserelay board 1
python -m courserelay handoff 1 > handoff.md
python -X utf8 -m unittest discover -s tests -v
```

编号以实际返回值为准。中文重定向建议使用 PowerShell 7 或显式 UTF-8 输出。
